# Silverfell Homebrew Tap

Homebrew cask for [BoltPage](https://github.com/Silverfell/BoltPage), a fast, lightweight Markdown viewer and editor.

## Install

```sh
brew tap Silverfell/tap
brew install --cask boltpage
```

## Update

```sh
brew upgrade --cask boltpage
```

## Uninstall

```sh
brew uninstall --cask boltpage
```

Casks are published from the [BoltPage repository](https://github.com/Silverfell/BoltPage); each release updates `Casks/boltpage.rb` with the new version and DMG checksums.
